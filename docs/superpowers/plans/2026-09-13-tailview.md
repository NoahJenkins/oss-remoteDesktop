# Tailview Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a native macOS viewer that lists Tailscale peers and opens an in-app Screen Sharing/VNC or RDP session with text clipboard.

**Architecture:** Testable Swift package (`TailviewCore`) owns discovery, profiles, session lifecycle, and a protocol-agnostic `RemoteSession`. The macOS app is a SwiftUI shell. VNC/ARD is RoyalVNC behind `VNCSession`. RDP is IronRDP behind a UniFFI crate and `RDPSession`.

**Tech Stack:** Swift 6 / SwiftUI / Swift Testing, macOS 14+, RoyalVNCKit, IronRDP 0.16 + UniFFI, Tailscale LocalAPI over a unix socket, Keychain, MIT license.

**Spec:** `docs/superpowers/specs/2026-09-13-tailview-design.md`

## Global Constraints

- Native macOS viewer (SwiftUI). No custom host/agent on remotes.
- MIT. Do not link libvncclient (GPL-2).
- App is not sandboxed (unix socket + `100.x` connections).
- VNC/Screen Sharing: RoyalVNC (MIT), including ARD auth type 30.
- RDP: IronRDP behind UniFFI only. VNC stays Swift.
- LocalAPI over the Tailscale unix socket. Do not shell out to the `tailscale` CLI.
- Profiles: `~/Library/Application Support/Tailview/profiles.json`, keyed by Tailscale stable node id.
- Connect uses Tailscale IPv4 (`100.x`) if present, otherwise IPv6.
- Poll LocalAPI about every 2 seconds.
- Fail-over pair: VNC/Screen Sharing ↔ RDP (ports 5900 ↔ 3389). Auth failure does not fail over.
- No automatic port scans. No private `ScreenSharing.framework`.
- Clipboard v1 is plain text only. No file transfer, audio, or multi-monitor picker.
- Hide `Self`. Offline / not-connectable rows stay visible with Connect disabled.
- Reconnect is an explicit button, not a silent retry loop.

```swift
public enum ProtocolSuggestion: Equatable, Sendable {
    case connectable(DesktopProtocol, port: UInt16)
    case notConnectable(reason: String)
}

public enum ProtocolHeuristic {
    public static func suggest(os: String) -> ProtocolSuggestion {
        switch os.lowercased() {
        case "macos":
            return .connectable(.screenSharing, port: 5900)
        case "linux":
            return .connectable(.vnc, port: 5900)
        case "windows":
            return .connectable(.rdp, port: 3389)
        case "ios":
            return .notConnectable(reason: "iOS devices cannot host a desktop session")
        case "android":
            return .notConnectable(reason: "Android devices cannot host a desktop session")
        default:
            return .notConnectable(reason: "No desktop protocol for OS \(os)")
        }
    }

    public static func failover(from desktopProtocol: DesktopProtocol) -> (DesktopProtocol, UInt16) {
        switch desktopProtocol {
        case .vnc, .screenSharing:
            return (.rdp, 3389)
        case .rdp:
            return (.vnc, 5900)
        }
    }
}
```

`Endpoint.swift`: treat a host as IPv4 if it contains `.` and does not contain `:`.

```swift
public struct Endpoint: Equatable, Sendable {
    public var host: String
    public var port: UInt16

    public init(host: String, port: UInt16) {
        self.host = host
        self.port = port
    }

    public static func preferredHost(ips: [String]) -> String? {
        if let ipv4 = ips.first(where: { $0.contains(".") && !$0.contains(":") }) {
            return ipv4
        }
        return ips.first
    }
}
```

```rust
pub enum RdpError {
    #[error("connection refused")] ConnectionRefused,
    #[error("timeout")] Timeout,
    #[error("handshake failed")] HandshakeFailed,
    #[error("authentication failed")] AuthenticationFailed,
    #[error("dropped")] Dropped,
}

#[uniffi::export]
pub fn rdp_connect(host: String, port: u16, username: String, password: String) -> Result<Arc<RdpSession>, RdpError>;

#[uniffi::export]
impl RdpSession {
    pub fn disconnect(&self);
    pub fn send_pointer(&self, x: u16, y: u16, left: bool, right: bool, middle: bool);
    pub fn send_scancode(&self, scancode: u16, down: bool);
    pub fn send_clipboard_text(&self, text: String);
    pub fn poll_frame(&self) -> Option<RdpFrame>; // width, height, rgba
    pub fn poll_clipboard(&self) -> Option<String>;
}

pub struct RdpFrame { pub width: u32, pub height: u32, pub rgba: Vec<u8> }
```
